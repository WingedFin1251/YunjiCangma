## 项目速览

- **平台**: HarmonyOS NEXT (API 6.1.0)
- **语言**: ArkTS（TypeScript 严格子集）
- **架构**: Stage Model + ArkUI 声明式 UI
- **数据源**: GitHub REST API v3 + OAuth Web Flow
- **设计**: 全局深色模式（V1.0 规范，唯一主题）
